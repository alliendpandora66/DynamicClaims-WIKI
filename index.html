DynamicClaims: Documentación Oficial

DynamicClaims es una plataforma geopolítica integral para servidores Paper (compilada para Paper 1.21.4 con Java 21). Unifica territorios, naciones, elecciones, guerra civil, guerras tácticas, misiles, economía con Patrón Oro, industria autónoma, pandemias y un Atlas Web propio dentro de un solo comando raíz: /dc.

¿Cómo está organizada esta Wiki? Para evitar confusiones entre lo que puede hacer un jugador normal y lo que requiere permisos administrativos o acceso a los archivos del servidor, toda la documentación se divide en 3 secciones independientes: 1. Usuario / Jugador Común, 2. Staff y 3. Operador.

Resumen Rápido: ¿Qué puede hacer cada perfil?

Perfil / Cargo Cómo se obtiene Qué puede hacer realmente en el servidor
Ciudadano / Jugador Entrar al servidor y unirse a una región (/dc unirse <REGION>) Usar /dc menu, teletransportarse a su región (/dc inicio), votar en elecciones (/dc elecciones) y aprobación de gobierno (/dc gobierno), usar el banco (/dc banco), comerciar en subastas (/dc mercado) y tienda (/dc tienda), donar XP a ciencia (/dc tecnologias donar), usar el mapa táctico (/dc mapa), entrar al Atlas Web (/dc mapa-web) y reclamar recompensas de rango (/dc rango).
Militar Activo Designado por el Líder o Colíder en /dc poblacion (dentro del cupo max-soldiers) Requisito obligatorio para guerras: Solo los ciudadanos con rango militar reconocido y plaza activa pueden conquistar o defender chunks, participar en Zonas de Guerra, sumar bajas bélicas, recibir efectos de moral y usar la reaparición del frente.
Alcalde / Dueño Regional Asignado a una región o nombrado desde /dc menu Fijar el punto de aparición local (/dc establecer-inicio), invitar ciudadanos a su región (/dc invitar <JUGADOR>), gestionar banderas locales y (si el servidor activa claims.allow-region-owners: true) reclamar/liberar chunks desde el Atlas Web.
Líder / Colíder Nacional Dueño de la capital, ganador electoral, canje de /dc codigo <CODIGO> o nombrado con /dc nacion asignar-colider Promulgar las 7 Leyes Nacionales (/dc leyes), dirigir la diplomacia, alianzas, guerras y vasallaje (/dc diplomacia), administrar la tesorería y emitir billetes (/dc economia), investigar tecnologías (/dc tecnologias), asignar rangos militares y expulsar ciudadanos (/dc poblacion). Nota: Crear la moneda inicial y degradar colíderes es exclusivo del Líder/Dueño de Capital.
Staff (In-Game) Permiso dynamicclaims.command.admin, dynamicclaims.admin u OP Fundar regiones y naciones (/dc region crear, /dc nacion crear), reclamar/liberar chunks por comando (/dc reclamar, /dc liberar), generar códigos de liderazgo (/dc admin codigos), moderar jugadores, arbitrar guerras/pandemias/elecciones y usar los editores gráficos in-game de industria, tienda, recursos, crafteos y rangos.
Operador / Dev Acceso a consola, archivos plugins/DynamicClaims/ y código Activar/desactivar los 36 módulos (/dc admin modulos), configurar YAML y base de datos SQLite/MySQL, desplegar el servidor HTTP del Atlas Web (web-map.yml), vincular Dynmap/Squaremap y Discord Bot/Webhook, importar mapas GeoJSON/ZNodes, ejecutar auditorías/rollbacks y programar con PlaceholderAPI, GraalJS o UltraAPI v2.
