Operador / Consola

Instalación, Arquitectura de 36 Módulos, Base de Datos y Mantenimiento

Guía técnica para el propietario u operador del servidor encargada de la instalación, activación de subsistemas, persistencia de datos y diagnóstico de integridad.

1. Requisitos del Servidor e Instalación

Componente Versión Requerida Carácter Observaciones
Java Runtime (JVM) Java 21 (LTS) Obligatorio Compilado con --release 21.
Servidor Minecraft Paper 1.21.4 (api-version: 1.21) Obligatorio Usa APIs nativas de Paper y Bukkit.
PlaceholderAPI 2.12.2+ Obligatorio Declarado en depend: [PlaceholderAPI] dentro de plugin.yml.
TAB / LuckPerms / Dynmap / squaremap / WeaponMechanics Versiones compatibles 1.21 Opcional Integraciones automáticas detectadas en softdepend. El Atlas Web propio no requiere Dynmap ni Squaremap.

2. Los 36 Módulos Configurables y su Grafo de Dependencias

DynamicClaims divide su arquitectura en 36 módulos declarados bajo modules.<id>.enabled en config.yml. Todos están habilitados por defecto (excepto el servidor HTTP del Atlas Web, que además requiere enabled: true en web-map.yml).

  • /dc admin modulos listar: Muestra el estado de todos los módulos.
  • /dc admin modulos configurar <MODULO> info: Muestra su descripción, estado configurado, estado efectivo, dependencias directas/indirectas y módulos dependientes.
  • /dc admin modulos configurar <MODULO> <activar|desactivar>: Enciende o apaga un módulo en caliente sin reiniciar el servidor ni perder sus datos guardados.
Familia IDs de Módulos en config.yml Relaciones Clave de Dependencia
Núcleo Territorial claims, regions, nations, invitations, claim-visualizer, teleportation regions y nations dependen de claims. Desactivar claims pausa toda la jerarquía territorial.
Diplomacia y Guerra diplomacy, war, warzones, missiles, nuclear-weapons, combat, infamy warzones y missiles requieren war y regions. nuclear-weapons requiere missiles.
Política y Sociedad elections, government, ranks, technology Gobernanza nacional, elecciones, rangos (rangos.yml) y árbol científico.
Economía y Comercio economy, server-shop, auctions server-shop (/dc tienda) y auctions (/dc mercado) dependen de economy.
Producción y Supervivencia industry, resources, crafting, pandemic, guidebook, scaffold-grapple scaffold-grapple (/dc andamio) requiere claims.
Mapas, Red y Visuales web-map, map-integration, tactical-map, chat, nametags, discord, time, notifications web-map requiere claims, regions y nations; sus capas opcionales siguen el estado de cada módulo.
Seguridad y Extensión security, scripting Anti-glitch y motor GraalJS con carga perezosa (ahorra ~50 MB de RAM si scripts/ está vacío).

3. Base de Datos (SQLite / MySQL), Auditoría y Recuperación

El plugin opera con SQLite activo por defecto (o MySQL cambiando database.type: mysql en config.yml) combinando consultas asíncronas (DatabaseManager.runAsync()) con escritura atómica por lotes en archivos YAML (CoalescedAsyncFileWriter):

Comando de Operador Propósito de Mantenimiento
/dc admin recargar
(o /dynamicclaims:dc admin recargar)		 Ejecuta el plan unificado de recarga (ServiceRegistry.reloadAll()): respalda configuraciones modificadas, migra claves antiguas y recarga gestores, menús y mapas en orden seguro.
/dc admin auditar [reparar] Inspecciona la coherencia entre regiones, naciones, claims, capitales y módulos activos. Con reparar corrige desajustes automáticamente.
/dc admin diagnostico
/dc admin verificar-integridad		 Muestra métricas de memoria JVM (MemorySafetyWatchdog), estado de servicios, sesiones del Atlas Web e integridad de datos.
/dc admin sanear
/dc admin sincronizar		 Limpia referencias huérfanas y fuerza la sincronización entre cachés en memoria y almacenamiento persistente.
/dc admin migrar-bd Ejecuta la migración de datos territoriales y económicos hacia la base de datos SQL configurada.
/dc admin revertir <tiempo (1s,10m,1h,1d)> [action] [target] Revierte acciones registradas en el historial de auditoría dentro de la ventana de tiempo indicada.
/dc admin purgar-mapa <nación | all> [min-chunks] Limpia regiones residuales o fragmentos menores al mínimo de chunks especificado.
/dc admin uuid info <NACION> [REGION]
/dc admin uuid regenerar <NACION> [REGION]		 Consulta o regenera el UUID v4 persistente de una nación o región utilizado por integraciones de UltraAPI v2.
