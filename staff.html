Staff / Admin In-Game

Guía de Staff: Permisos, Jugadores, Territorios y Códigos

Esta sección está diseñada para los moderadores y administradores que asisten a los usuarios dentro de Minecraft: crear regiones o naciones, asignar líderes mediante códigos, gestionar miembros y supervisar el chat.

1. Permisos de Staff y Bypass Administrativo

Nodo de Permiso Por Defecto Facultades que otorga
dynamicclaims.command.admin
(o dynamicclaims.admin)		 op Acceso Administrativo Completo: Permite usar todos los subcomandos de /dc admin, fundar regiones/naciones, reclamar/liberar chunks, editar cualquier nación en menús o en el Atlas Web, y omite las restricciones de construcción, interacción, fronteras cerradas, combat-tag y tiempos de espera de teletransporte.
dynamicclaims.admin.spy false Permite activar /dc chat espiar para leer canales privados (Región, Nación y Alianza) sin conceder administración total.
dynamicclaims.leader false Habilita sugerencias de herramientas de liderazgo, pero NO concede administración global ni convierte al portador en líder de naciones ajenas.

2. Creación y Gestión de Regiones y Naciones

Los nombres nuevos admiten de 1 a 48 caracteres (letras, números, guiones - y guiones bajos _; sin espacios ni puntos). Al asociar una región a una nación, su identificador interno adopta el formato NACION_REGION:

Comando Uso Práctico para el Staff
/dc admin region crear <REGION> [PROPIETARIO|-] [MUNDO] Crea una región vacía. Usa - como propietario si deseas crearla sin dueño inicial. También puedes usar /dc region crear <REGION> o /dc crear <REGION> en tu mundo actual.
/dc admin nacion crear <NACION> <REGION_CAPITAL> Funda una nación soberana convirtiendo la región independiente indicada en su capital oficial (también /dc nacion crear <NACION> [REGION_CAPITAL]).
/dc reclamar [RADIO|auto|rellenar|confirmar|cancelar] Reclama chunks en el mundo para la región seleccionada (también puedes pintarlos cómodamente desde el Editor Territorial del Atlas Web con /dc mapa-web).
/dc liberar [RADIO|auto|rellenar|todo|confirmar|cancelar] Desreclama chunks de una región.
/dc admin region propietario <REGION> <JUGADOR> Asigna o transfiere la titularidad de una región a un jugador.
/dc admin region transferir <REGION> <NACION> Anexa una región independiente (o la traslada desde otra nación) hacia la nación destino conservando sus chunks y datos.
/dc admin nacion capital <NACION> <REGION> Cambia la región capital oficial de una nación existente.
/dc admin region renombrar <REGION> <NUEVO_NOMBRE> [confirmar]
/dc admin nacion renombrar <NACION> <NUEVO_NOMBRE> [confirmar]		 Cambia el nombre de una región o nación actualizando automáticamente todas sus referencias y conservando su UUID.
/dc admin region eliminar <REGION>
/dc admin nacion eliminar <NACION>		 Elimina una región o disuelve una nación (requiere confirmación con /dc admin confirmar si aplica).
/dc admin establecer-inicios <all | nación | región> Genera automáticamente puntos de aparición seguros (Home) en el centro de las regiones que aún no tengan uno configurado.

3. Códigos de Liderazgo (Entrega de Países a Usuarios)

La forma más limpia y segura de entregar una nación recién creada (o vacante) a un jugador que ganó una postulación en Discord es generarle un Código de Liderazgo:

Comando Explicación
/dc admin codigos crear <NACION> <JUGADOR> [dias] Genera un código único vinculado a esa nación y a ese jugador (caduca en 30 días por defecto si no se especifica duración). El jugador lo canjea con /dc codigo <CODIGO>.
/dc admin codigos menu Abre el panel gráfico de gestión de códigos de liderazgo.
/dc admin codigos listar [pagina]
/dc admin codigos info <CODIGO>		 Muestra los códigos activos o consulta el estado, creador y fecha de expiración de un código concreto.
/dc admin codigos eliminar <CODIGO>
/dc admin codigos limpiar		 Revoca un código específico o purga todos los códigos ya caducados/usados.
/dc admin codigos auditar [PAGINA] Muestra el historial de auditoría de códigos creados y canjeados.

4. Gestión de Jugadores, Roles y Moderación

Comando Función de Soporte / Moderación
/dc admin jugadores info <JUGADOR> Muestra la ficha completa de un jugador: regiones, nación, cargos, rango militar y estado.
/dc admin jugadores listar <region|nacion> <NOMBRE> Lista todos los miembros empadronados en una región o nación.
/dc admin jugadores unir <JUGADOR> <REGION> Incorpora forzosamente a un jugador dentro de una región.
/dc admin jugadores expulsar <JUGADOR> <REGION> Retira a un jugador de la región indicada. (Recuerda que no se puede expulsar al dueño de la capital ni al líder del gobierno activo sin relevarlos antes).
/dc admin jugadores rol <JUGADOR> <REGION> <lider|colider|alcalde|miembro> Asigna directamente el cargo político o regional del jugador en esa región/nación.
/dc chat espiar Activa o desactiva el modo Chat Spy para supervisar en tiempo real los mensajes enviados en los canales de Región, Nación y Alianza.
/dc admin guia dar <JUGADOR>
/dc admin guia libro [JUGADOR]		 Entrega el libro físico de la Guía interactiva a un usuario.
