Integración con Discord: Webhook y Bot Interactivo (JDA)

DynamicClaims se conecta con Discord mediante dos componentes complementarios controlados por el módulo discord: un Webhook Asíncrono para publicar noticias geopolíticas y un Bot JDA para el panel interactivo de roles de naciones y menciones automáticas.

1. Configuración Real en config.yml

discord:
  webhook:
    enabled: true
    url: 'https://discord.com/api/webhooks/TU_ID/TU_TOKEN'
    username: WWC-Diplomacia
    avatar-url: ''
    timeout-seconds: 10
    log-success: false
    events:
      war-declared: true
      war-started: true
      war-ended: true
      alliance-created: true
      alliance-dissolved: true
      pandemic-started: true
      pandemic-ended: true
      pandemic-spread: true
      pandemic-mutated: true
      vaccine-started: true
      vaccine-completed: true
      nation-created: true
      nation-deleted: true

  bot:
    enabled: true
    token: 'TU_TOKEN_DE_BOT_DISCORD'
    prefix: '!'
    role-prefix: ''
    role-channel-id: ''     # Se autoguarda al usar !set_chanel en Discord
    role-message-id: ''     # ID del mensaje interactivo fijado (se autoguarda)
    auto-update-panel: true # Actualiza el panel cuando se crea o elimina una nación
    mention-roles: true     # Menciona automáticamente (@Nación) en alertas bélicas

2. Puesta en Marcha del Bot JDA y Comandos

  1. Coloca el token de tu aplicación de Discord en discord.bot.token y asegúrate de que el bot tenga permisos de Manage Roles, Send Messages y View Channels en tu servidor de Discord.
  2. En el canal de Discord donde quieras publicar el selector de naciones, escribe el comando con el prefijo configurado (por defecto !set_chanel) o utiliza los comandos administrativos dentro de Minecraft.
Comando en Minecraft Función
/dc admin discord info Muestra el estado de conexión del Webhook y del Bot JDA, canal vinculado y opciones activas.
/dc admin discord panel Fuerza la actualización y republicación del panel interactivo de roles de naciones en Discord.
/dc admin discord recargar Recarga la configuración de Discord y reconecta el Bot JDA sin reiniciar el servidor de Minecraft.
