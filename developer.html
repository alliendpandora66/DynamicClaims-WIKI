Java API (`DynamicClaimsAPI`) y UltraAPI v2

DynamicClaims expone dos puntos de integración públicos para plugins de Paper / Spigot (Java 21):

  • UltraAPI v2 (com.wwcstudios.api.ultra.*): Servicio desacoplado registrado en el ServicesManager de Bukkit con 289 operaciones públicas (273 de gameplay en UltraGameplay + 16 de dibujo vectorial en el Atlas Web vía UltraLayer). Retorna records inmutables definidos en UltraData sin exponer managers internos.
  • Fachada Singleton (com.wwcstudios.api.DynamicClaimsAPI): Acceso directo mediante DynamicClaimsAPI.get() a los 14 subsistemas geopolíticos del plugin.

1. Dependencia Maven y `plugin.yml`

Al compilar el proyecto se generan dos artefactos: el plugin completo y el contrato ligero DynamicClaims-0.1Beta1-ultra-api.jar. Declara la dependencia con <scope>provided</scope> (no reubiques ni empaquetes las clases de UltraAPI dentro de tu JAR):

<dependency>
    <groupId>com.wwcstudios</groupId>
    <artifactId>DynamicClaims</artifactId>
    <version>0.1Beta1</version>
    <classifier>ultra-api</classifier>
    <scope>provided</scope>
</dependency>

En el archivo plugin.yml de tu plugin consumidor:

name: MiAddonGeopolitico
version: "1.0.0"
main: com.ejemplo.MiPlugin
api-version: "1.20"
softdepend:
  - DynamicClaims

2. Descubrimiento del Servicio, Hilos y Concurrencia

Descubre UltraAPI a través del ServicesManager de Bukkit. Las llamadas síncronas de UltraGameplay se ejecutan de forma segura en el hilo principal de Bukkit y devuelven copias inmutables (incluyendo clones de Location). Si consultas desde un hilo asíncrono o worker SQL, utiliza game.executeAsync(...):

import com.wwcstudios.api.ultra.UltraAPI;
import com.wwcstudios.api.ultra.UltraGameplay;
import com.wwcstudios.api.ultra.UltraData.*;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;

public void consultarEstado(Player player, Player victim) {
    UltraAPI ultra = Bukkit.getServicesManager().load(UltraAPI.class);
    if (ultra == null || !ultra.isGameplayAvailable()) return;

    UltraGameplay game = ultra.game();

    // Consultas síncronas desde el hilo principal de Bukkit
    PlayerStatus estado = game.getPlayerStatus(player.getUniqueId());
    RegionStatus territorio = game.getRegionStatus("Aurora_Capital");
    DiplomacyStatus diplomacia = game.getDiplomacyStatus("Aurora", "Boreal");
    PvpDecision pvp = game.getPvpDecision(player, victim);

    // Modificación administrativa directa
    game.setNationPvpEnabled("Aurora", false);

    // Desde un worker asíncrono o callback SQL: se ejecuta en Bukkit sin bloquear tu hilo
    game.executeAsync(api -> api.getPlayerStatus(player.getUniqueId()))
        .thenAccept(snapshot -> getLogger().info("En combate: " + snapshot.combat()));
}

Regla de oro con executeAsync: Nunca llames a .join() ni .get() sobre el CompletableFuture desde el hilo principal de Bukkit para evitar interbloqueos (deadlocks). Al recargar o reiniciar DynamicClaims, vuelve a descubrir el servicio con ServicesManager.load(UltraAPI.class).

3. UUIDs Persistentes de Regiones y Naciones

Las regiones y naciones cuentan con un UUID v4 inmutable (persistido en YAML y SQL) que se mantiene intacto aunque el territorio sea renombrado (ej. de Polonia_Norte a Alemania_Norte) o transferido tras una guerra. Guarda siempre el UUID en la base de datos de tu plugin y resuelve el nombre vigente en memoria:

import com.wwcstudios.api.ultra.UltraAPI;
import com.wwcstudios.api.ultra.UltraGameplay;
import com.wwcstudios.api.ultra.UltraData.*;
import java.util.UUID;

// 1. Obtener el UUID persistente para guardarlo en tu plugin
UUID regionId = game.getRegionUUID("Aurora_Puerto");
UUID nationId = game.getNationUUID("Aurora");

// 2. Consultar estado directamente por UUID o resolver su nombre actual en O(1)
RegionStatus region = game.getRegionStatusByUUID(regionId);
NationStatus nation = game.getNationStatusByUUID(nationId);
String currentRegionName = game.getRegionNameByUUID(regionId);
String currentNationName = game.getNationNameByUUID(nationId);

// 3. Patrón recomendado para consumidores asíncronos: resolver y mutar en el mismo bloque
game.executeAsync(api -> {
    String current = api.getRegionNameByUUID(regionId);
    if (current == null) return false; // La región fue eliminada o su UUID regenerado
    api.setRegionDescription(current, "Zona portuaria comercial");
    api.setRegionFlag(current, "explosions", false);
    return true;
});

4. Leyes Nacionales y Flags Regionales de Otros Plugins

Tu plugin puede registrar sus propias leyes nacionales (ámbito RuleScope.NATION) y flags regionales (ámbito RuleScope.REGION) con nombre, descripción, valor por defecto e icono de inventario. DynamicClaims persiste automáticamente sus valores en YAML/SQL, sincroniza las leyes nacionales en todas las regiones del país e inyecta un menú paginado en /dc leyes (botón Leyes de otros plugins en el slot 47) y autocompletado en /dc admin region bandera:

import com.wwcstudios.api.ultra.UltraAPI;
import com.wwcstudios.api.ultra.UltraGameplay;
import com.wwcstudios.api.ultra.UltraData.*;
import com.wwcstudios.api.ultra.CustomRuleChangeEvent;
import org.bukkit.Material;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerTeleportEvent;

public class ReglasAddonListener implements Listener {
    private String leyTeletransporte;
    private String flagPortales;
    private UltraGameplay game;

    public void registrarReglas( org.bukkit.plugin.Plugin miPlugin, UltraGameplay game) {
        this.game = game;

        // Devuelve la clave con namespace automático: "miplugin:teletransporte"
        this.leyTeletransporte = game.registerNationLaw(miPlugin, "teletransporte",
            new RuleOptions("Permitir Teletransporte", "Permite usar /tpa dentro de la nación", true, Material.ENDER_PEARL));

        // Devuelve la clave con namespace automático: "miplugin:portales"
        this.flagPortales = game.registerRegionFlag(miPlugin, "portales",
            new RuleOptions("Portales Dimensionales", "Permite cruzar portales en esta región", true, Material.OBSIDIAN));
    }

    @EventHandler
    public void onTeleport(PlayerTeleportEvent event) {
        String region = game.getRegionAt(event.getTo());
        if (region == null) return;

        // getEffectiveRegionFlags combina flags locales + leyes nacionales heredadas
        Boolean permitido = game.getEffectiveRegionFlags(region).get(leyTeletransporte);
        if (Boolean.FALSE.equals(permitido)) {
            event.setCancelled(true);
            event.getPlayer().sendMessage("§cEsta nación ha prohibido el teletransporte por ley.");
        }
    }

    @EventHandler
    public void onCustomRuleChange(CustomRuleChangeEvent event) {
        CustomRule rule = event.getRule();
        String destino = event.getTargetName(); // Nombre de la nación o región
        boolean antes = event.getPreviousValue();
        boolean ahora = event.getValue();
        Bukkit.getLogger().info("[Regla Externa] " + rule.key() + " en " + destino + ": " + antes + " -> " + ahora);
    }
}

5. Capas Vectoriales en el Atlas Web (`UltraLayer` y `AtlasDrawing`)

El servicio UltraAPI permite publicar marcadores, líneas, polígonos (con huecos), círculos y etiquetas de texto rotables sobre el Mapa Web Integrado (Atlas Web) sin depender de Dynmap ni Squaremap. Registra la capa en el hilo principal; una vez obtenida la instancia de UltraLayer, puedes invocar put, putAll, remove, clear o close desde cualquier hilo:

import com.wwcstudios.api.ultra.UltraAPI;
import com.wwcstudios.api.ultra.UltraLayer;
import com.wwcstudios.api.ultra.LayerOptions;
import com.wwcstudios.api.ultra.AtlasDrawing;
import java.util.List;
import java.util.UUID;

// 1. Registrar capa en el hilo principal con icono personalizado en el panel "Capas"
UltraLayer layer = ultra.registerLayer(
    this,
    "rutas_comerciales",
    LayerOptions.of("Rutas Comerciales").withIcon(AtlasDrawing.Icon.ANCHOR)
);

// 2. Publicar dibujos inmutables (thread-safe y atómico con putAll)
UUID worldId = Bukkit.getWorld("world").getUID();
AtlasDrawing.Style estiloAzul = new AtlasDrawing.Style("#81d4fa", "#2196f3", 2.0, 0.85);

layer.putAll(List.of(
    new AtlasDrawing.Marker(
        "puerto_central",
        worldId,
        new AtlasDrawing.Point(120.0, -80.0),
        AtlasDrawing.Icon.ANCHOR,
        20.0,
        estiloAzul,
        new AtlasDrawing.Info("Puerto Central", "Salida marítima principal de mercancías.")
    ),
    new AtlasDrawing.Polyline(
        "ruta_maritima_1",
        worldId,
        List.of(new AtlasDrawing.Point(120.0, -80.0), new AtlasDrawing.Point(340.0, 160.0)),
        estiloAzul,
        new AtlasDrawing.Info("Ruta Comercial Norte", "Puerto Central → Mercado Continental")
    ),
    new AtlasDrawing.Circle(
        "zona_exclusiva",
        worldId,
        new AtlasDrawing.Point(120.0, -80.0),
        75.0,
        AtlasDrawing.Style.of("#38bdf8"),
        new AtlasDrawing.Info("Aguas Portuarias", "Radio de protección de 75 bloques")
    )
));
