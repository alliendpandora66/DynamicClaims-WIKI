Staff / Arbitraje

Arbitraje de Staff: Guerras, Gobierno, Pandemias y Leyes

Guía de comandos para que el Staff pueda supervisar o intervenir en conflictos geopolíticos, ajustar cupos militares, bloquear leyes específicas, lanzar eventos sanitarios o adelantar el calendario Roleplay.

1. Control de Guerras, Treguas y Zonas de Guerra

Bypass en Declaraciones Administrativas: Cuando un miembro del Staff inicia una guerra (por comando o desde el menú de diplomacia), el sistema omite los requisitos de población mínima, soberanía compartida, infamia, alianzas, treguas y horas de preparación, pero sigue validando que no exista otra guerra activa en conflicto con esos bandos.

Comando Efecto
/dc admin guerra iniciar <ATACANTE> <DEFENSORA> [REGION_OBJETIVO] Inicia inmediatamente una guerra entre dos naciones.
/dc admin guerra terminar [true|false] Finaliza la guerra en curso declarando ganador al atacante (true) o al defensor (false).
/dc admin guerra cancelar Aborta la guerra activa o programada sin aplicar cambios territoriales ni sanciones.
/dc admin guerra chunks <CANTIDAD>
/dc admin guerra info		 Ajusta la cantidad de chunks en la contienda o muestra el diagnóstico completo de la guerra actual.
/dc admin guerra tregua <establecer|eliminar|listar> [nacion1] [nacion2] [dias] Impone una tregua obligatoria entre dos naciones, elimina una existente o lista las vigentes.
/dc admin zona-guerra crear <REGION> [meta%]
/dc admin zona-guerra eliminar <REGION>		 Convierte una región en una Zona de Guerra abierta o la desactiva. Puedes cambiar el porcentaje de victoria con /dc admin zona-guerra meta <REGION> <meta%> y consultar con info o listar.

2. Cupo Militar Nacional y Estados Títeres (Vasallaje)

Comando Efecto
/dc admin militares max <NACION> <CANTIDAD> Establece un límite máximo exclusivo de soldados para esa nación (tiene prioridad sobre el valor global de config.yml). Usar 0 impide reclutar y participar en guerras.
/dc admin militares info <NACION> Muestra el censo militar actual, el tope máximo, las plazas libres y el origen del límite (global, placeholder o exclusivo).
/dc admin militares restablecer <NACION> Borra el límite exclusivo de esa nación para que vuelva a usar la configuración general del servidor.
/dc admin titeres crear <OVERLORD> <TITERE>
/dc admin titeres eliminar <TITERE>
/dc admin titeres listar [NACION]		 Establece una relación de vasallaje (convirtiendo a TITERE en estado subordinado de OVERLORD), libera a un estado títere o lista las relaciones de soberanía.

3. Gobierno, Guerra Civil y Partidos Electorales

Comando Efecto
/dc admin gobierno info <NACION> Consulta los votos de aprobación, desaprobación, líder rebelde y estado de Guerra Civil de una nación.
/dc admin gobierno iniciar-guerra-civil <NACION> Desata inmediatamente una Guerra Civil activa en la nación indicada.
/dc admin gobierno terminar-guerra-civil <NACION> <rebeldes|leales> Finaliza la Guerra Civil otorgando la victoria a la facción rebelde o al gobierno leal.
/dc admin gobierno limpiar-votos <NACION> Reinicia a cero todos los votos de aprobación y desaprobación de una nación.
/dc admin partidos crear <NACION> <CANDIDATO> <PARTIDO> <IDEOLOGIA> Registra administrativamente una candidatura electoral en una nación.
/dc admin partidos ganador <NACION> <CANDIDATO> Proclama ganador electoral al candidato indicado. También puedes usar eliminar, tipo, reiniciar, limpiar-huerfanos y listar.
/dc admin prueba votaciones <iniciar|terminar|abrir> Permite iniciar, abrir o cerrar manualmente un ciclo de prueba electoral.

4. Disponibilidad de Leyes y Banderas

El Staff puede decidir qué leyes constitucionales tienen permitido cambiar los líderes y cuáles quedan bloqueadas con su valor actual:

Comando Efecto
/dc admin leyes global <FLAG> <habilitar|deshabilitar> Permite o bloquea globalmente la edición de una ley (ej: openNation, electionsEnabled, pvpEnabled, alliesCanBuild, etc.).
/dc admin leyes nacion <NACION> <FLAG> <habilitar|deshabilitar|heredar> Crea una excepción para una nación específica o usa heredar para volver a la regla global.
/dc admin leyes listar [global|NACION] Muestra qué leyes están habilitadas o bloqueadas y el origen de cada política.
/dc admin region bandera <NACION|REGION> <LEY> <true|false> Cambia directamente el valor booleano de cualquiera de las 7 leyes nacionales o reglas externas registradas.

5. Pandemias, Radiación, Tecnología y Tiempo Roleplay

Comando Efecto
/dc admin pandemia crear <NOMBRE> <SEVERIDAD 1-5> <NACION_ORIGEN> Inicia un nuevo brote epidemiológico en la nación origen indicada (o abre el asistente desde /dc admin pandemia).
/dc admin pandemia configurar <NOMBRE> <PARAMETRO> <VALOR> Ajusta en caliente tasas de contagio, mortalidad o severidad de una pandemia activa.
/dc admin pandemia vacuna <PANDEMIA> / vacunar <PANDEMIA> / terminar <PANDEMIA> Completa la vacuna, inmuniza a los afectados o erradica inmediatamente la pandemia.
/dc admin radiacion listar
/dc admin radiacion limpiar <todo|radio|id>		 Enumera las zonas contaminadas por impactos nucleares o descontamina un radio, un ID específico o todo el mapa.
/dc admin tecnologia dar|eliminar|puntos|establecer-puntos|desbloquear-todo|reiniciar <NACION> ... Otorga o retira tecnologías específicas, suma puntos de ciencia, desbloquea todo el árbol o reinicia el progreso de una nación.
/dc admin tecnologia validar [NACION|todo]
/dc admin tecnologia reparar [NACION|todo]		 Verifica y repara inconsistencias en los permisos y nodos tecnológicos de las naciones.
/dc admin tiempo establecer <HH:MM|DD.MM.AA> [HH:MM|DD.MM.AA]
/dc admin tiempo sumar <1d|1h|1m|1s...>		 Fija o adelanta la fecha y hora del calendario ficticio de Roleplay del servidor.
