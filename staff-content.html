Staff / Constructores

Editores In-Game: Industria, Tienda, Divisas, Recursos y Rangos

DynamicClaims incluye editores visuales en inventarios (GUI) para que el Staff pueda diseñar estructuras, configurar producciones, añadir productos a la tienda o crear recetas sin tener que editar archivos YAML manualmente.

1. Estructuras, Tipos de Industria y Aeropuertos

Comando Descripción detallada
/dc admin estructura crear <NOMBRE> Entrega la herramienta selectora para marcar las dos esquinas de una construcción en el mundo y guardarla como estructura 3D.
/dc admin industria tipos crear <ID>
/dc admin industria tipos editar <ID>
/dc admin industria tipos menu		 Crea o edita una definición concreta de edificio (ej: mina_cobre) en un editor visual: categoría funcional, estructura 3D, ítem colocador, capacidad, tiempo de construcción, intervalo de ciclo, modo de probabilidad (tiradas independientes vs. ponderada) y hasta 7 resultados con ItemStack exacto.
/dc admin industria dar <JUGADOR> <EDIFICIO> [CANTIDAD] Entrega en el inventario del jugador el ítem colocador de un edificio industrial registrado.
/dc admin industria receta <crear|editar|eliminar|listar> <NOMBRE> Abre el editor visual de recetas para fábricas (ingredientes, resultado y duración del ciclo).
/dc admin industria recursos <crear|eliminar|listar> [NOMBRE] Registra el ítem sostenido en mano en el catálogo de recursos industriales.
/dc admin industria listar [REGION|todo|huerfanos] [PAGINA]
/dc admin industria info <ID>
/dc admin industria teletransportar <ID>		 Inspecciona todos los edificios colocados en el servidor, revisa su estado o te teletransporta a su ubicación.
/dc admin industria eliminar <REGION> <EDIFICIO> [si|no]
/dc admin industria purgar <REGION> [si|no]		 Elimina un edificio concreto (si hay varios del mismo tipo en la región se seleccionan como mina_1, mina_2, etc.) o todos los de una región. si elimina también los bloques físicos del mundo y no conserva la construcción.
/dc admin industria aeropuertos <listar|info|teletransportar|eliminar> ... Gestiona el registro de terminales aéreas operativas en el servidor.

2. Gestión de Divisas y Tienda Oficial del Servidor

Comando Descripción
/dc admin tienda crear <precioCompraOro> <precioVentaOro> [ambos|solo-compra|solo-venta] Añade el ítem que tienes en tu mano principal al catálogo de /dc tienda con precios referenciados en oro.
/dc admin tienda menu
/dc admin tienda editar <id> <compraOro> <ventaOro> [modo]
/dc admin tienda eliminar <id> / listar		 Abre el editor visual de la tienda del servidor o modifica/retira productos por su ID.
/dc admin divisas crear <CODIGO> <SIMBOLO> <NOMBRE> [oro] [billetes] Registra una nueva divisa especificando código de 3 letras, símbolo, nombre y respaldo inicial.
/dc admin divisas asociar <CODIGO> <NACION>
/dc admin divisas desvincular <CODIGO|NACION>		 Vincula o desvincula una moneda oficial con una nación.
/dc admin divisas oro <CODIGO> <ORO>
/dc admin divisas billetes <CODIGO> <BILLETES>		 Ajusta directamente las reservas de oro o el total de billetes emitidos de una moneda.
/dc admin divisas dar <JUGADOR> <CODIGO> <CANTIDAD>
/dc admin divisas saldo-virtual <JUGADOR> <CODIGO> <CANTIDAD>		 Entrega billetes físicos a un jugador o fija su saldo bancario virtual en esa divisa. También existen emitir, quemar, modelo <1-4>, eliminar, limpiar-huerfanos y listar.

3. Recursos Mineros, Crafteos Custom, Rangos y Herramientas

Comando Descripción
/dc admin recursos <crear|editar|eliminar|listar> [NOMBRE] Abre el editor visual para configurar drops personalizados al picar bloques (probabilidad, herramienta requerida y encantamientos).
/dc admin crafteos crear <NOMBRE> [tipo]
/dc admin crafteos <editar|eliminar|listar|recargar>		 Diseña recetas personalizadas en mesa de crafteo u horno colocando los ingredientes y el resultado directamente en el editor GUI.
/dc admin rangos asignar <JUGADOR> <RANGO> [DURACION]
/dc admin rangos eliminar <JUGADOR>		 Otorga un rango de rangos.yml a un jugador (ej: 30d, 7d o permanente) o se lo retira.
/dc admin rangos editar <RANGO>
/dc admin rangos permiso <crear|eliminar|listar> <RANGO> [PERMISO]		 Abre el editor visual de recompensas del rango o administra sus nodos de permiso Bukkit. Usa reiniciar-recompensa <JUGADOR> para permitirle reclamar su kit nuevamente.
/dc admin herramientas menu
/dc admin herramientas dar <JUGADOR> <HERRAMIENTA>		 Abre el catálogo de herramientas especiales de DynamicClaims (como la pala de trinchera) o entrega una directamente a un jugador.
