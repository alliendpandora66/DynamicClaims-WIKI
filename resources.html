Operador

Recursos, Drops, Vehículos (`vehiculos.yml`) e Importación GeoJSON

Guía técnica para configurar la extracción de recursos estratégicos por territorio, integrar plugins de vehículos/artillería con el sistema de regiones y proyectar mapas de la Tierra real en tu servidor.

1. Drops de Bloques y Mobs (`recursos_drops.yml`)

El archivo plugins/DynamicClaims/recursos_drops.yml permite que bloques minados o entidades abatidas suelten ítems registrados en el catálogo de Recursos Personalizados (/dc admin recursos), filtrando por bioma, región o nación.

🛡️ Anti-Exploit de Bloques Colocados (`PlacedBlockTracker`)

DynamicClaims rastrea los bloques colocados por jugadores mediante PlacedBlockTracker (consultable también vía API con isBlockPlayerPlaced(Block)). Si un jugador coloca una mena y la vuelve a picar, no recibirá drops personalizados, impidiendo granjas infinitas con Toque de Seda.

block_drops:
  IRON_ORE:
    - resource: "acero_puro"
      chance: 15.0        # Probabilidad porcentual (0.0 a 100.0)
      min_amount: 1
      max_amount: 2
      biomes: []          # Vacío = todos los biomas (ej. [TAIGA, DRIPSTONE_CAVES])
      regions: []         # Vacío = todas las regiones (o restringir a ["Ruhr", "Urales"])
      nations: []         # Vacío = todas las naciones
  DEEPSLATE_IRON_ORE:
    - resource: "acero_puro"
      chance: 25.0
      min_amount: 1
      max_amount: 3

mob_drops:
  ZOMBIE:
    - resource: "tejido_infectado"
      chance: 5.0
      min_amount: 1
      max_amount: 1
      biomes: []
      regions: []
      nations: []

2. Excepciones para Vehículos y Artillería (`vehiculos.yml`)

El archivo plugins/DynamicClaims/vehiculos.yml permite que tanques, aviones, torretas y proyectiles de otros plugins tengan reglas específicas de rotura de bloques y PvP en regiones reclamadas, zonas de guerra y tierras libres. DynamicClaims detecta el tipo de vehículo buscando la clave settings.tag-key (por defecto "wwc_type") en:

  1. Metadata de Bukkit (entity.hasMetadata("wwc_type")).
  2. PersistentDataContainer (PDC) del proyectil, vehículo o conductor.
  3. Scoreboard Tags (por ejemplo "wwc_type:tanque" o "tanque").
settings:
  enabled: true
  tag-key: "wwc_type" # Clave buscada en Metadata, PDC y Scoreboard Tags

default-rules:
  block-destruction:
    allow-in-claims: false
    allow-in-war: true
    allow-in-wilderness: true
    whitelist-blocks: []
    blacklist-blocks:
      - BEDROCK
      - BARRIER
      - CHEST
      - TRAPPED_CHEST
      - ENDER_CHEST
      - SPAWNER
  pvp:
    bypass-claim-pvp-protection: false
    allow-in-war: true
    allow-damage-to-vehicle-in-claims: true
    allow-mount-in-claims: true

types:
  tanque:
    block-destruction:
      allow-in-claims: true
      allow-in-war: true
      allow-in-wilderness: true
      whitelist-blocks: []
      blacklist-blocks:
        - BEDROCK
        - BARRIER
        - SPAWNER
    pvp:
      bypass-claim-pvp-protection: true
      allow-in-war: true
      allow-damage-to-vehicle-in-claims: true
      allow-mount-in-claims: true

  avion:
    block-destruction:
      allow-in-claims: false
      allow-in-war: true
      allow-in-wilderness: true
      whitelist-blocks: []
      blacklist-blocks:
        - BEDROCK
        - BARRIER
    pvp:
      bypass-claim-pvp-protection: false
      allow-in-war: true
      allow-damage-to-vehicle-in-claims: true
      allow-mount-in-claims: true

3. Importación Geográfica Masiva (GeoJSON y ZNodes)

Para servidores geopolíticos a escala de la Tierra (Earth SMP), DynamicClaims convierte polígonos reales (latitud/longitud) o exportaciones de ZNodes en regiones y naciones reclamadas por chunks.

Configuración de Proyección Geográfica (`config.yml`)

geojson:
  projection: equirectangular # "equirectangular" o "mercator"
  world-width: 73728          # Ancho total del mapa en bloques (eje X, 360° de longitud)
  world-height: 36864         # Alto total del mapa en bloques (eje Z, 180° de latitud)
  origin-x: 0                 # Coordenada X del bloque equivalente a longitud 0° (Greenwich)
  origin-z: 0                 # Coordenada Z del bloque equivalente a latitud 0° (Ecuador)
  world: world

Comandos de Importación

Comando Permiso Descripción
/dc admin importar geojson nacion <archivo.geojson> <nación> [mundo] [color_hex] dynamicclaims.admin Crea o actualiza la nación indicada, genera sus regiones a partir de las geometrías del GeoJSON y reclama todos los chunks interiores.
/dc admin importar geojson region <archivo.geojson> [nombre_region] [mundo] dynamicclaims.admin Importa un polígono GeoJSON directamente como una o varias regiones en el mundo especificado.
/dc admin importar znodes <towns.json> <world.json> [mundo] dynamicclaims.admin Migra territorios, ciudades y naciones desde archivos de exportación del sistema ZNodes.
