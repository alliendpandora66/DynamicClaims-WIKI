GraalJS Engine

Motor de Scripting (GraalVM JavaScript)

DynamicClaims integra el motor GraalJS para ejecutar scripts en plugins/DynamicClaims/scripts/*.js sin necesidad de compilar un plugin en Java. El motor se inicializa de forma diferida (lazy initialization) únicamente cuando el módulo scripting está activo y existen archivos .js en la carpeta.

1. Comandos de Gestión y Ejecución de Scripts

Comando Permiso / Rol Descripción
/dc admin scripts listar dynamicclaims.admin Muestra todos los scripts activos, su nombre, versión, descripción y estado de carga.
/dc admin scripts cargar <archivo.js> dynamicclaims.admin Carga y evalúa un archivo .js específico desde plugins/DynamicClaims/scripts/.
/dc admin scripts descargar <archivo.js> dynamicclaims.admin Desactiva el script en caliente, desregistrando automáticamente todos sus eventos y comandos.
/dc admin scripts recargar dynamicclaims.admin Vuelca las bases de datos de scripts pendientes a disco, libera la memoria de contextos y recarga todos los .js.
/dc admin scripts diagnostico dynamicclaims.admin Inspecciona el estado del motor GraalJS, scripts cargados y comandos registrados.
/dc scripts ejecutar <nombre> [argumentos...] Jugador Ejecuta un comando registrado por un script mediante DynamicClaimsAPI.registerCommand(nombre, fn).

2. Variables Globales Inyectadas en cada Script

Al evaluarse un archivo .js, ScriptManager inyecta automáticamente los siguientes objetos globales en el contexto del script:

Objeto Global Tipo Java Real Métodos y Utilidad
DynamicClaimsAPI
(o su alias api)		 com.wwcstudios.scripting.DynamicClaimsAPI Hereda los 14 dominios completos de com.wwcstudios.api.DynamicClaimsAPI (regiones, naciones, UUIDs, divisas, oro, guerras, tecnología, pandemias, etc.) y añade:
• onEvent(eventClassName, callback)
• registerCommand(commandName, callback)
• getScriptDatabase(dbName)
Script
(o su alias script)		 ScriptManager.ScriptHelper Define los metadatos del script que se muestran en /dc admin scripts listar:
• Script.setName("Nombre")
• Script.setVersion("1.0")
• Script.setDescription("Descripción...")
plugin com.wwcstudios.App Instancia principal del plugin DynamicClaims.
server org.bukkit.Server Servidor de Bukkit (`Bukkit.getServer()`), útil para consultar jugadores conectados o mundos.
logger java.util.logging.Logger Logger del plugin (`logger.info(...)`, `logger.warning(...)`, `logger.severe(...)`).

3. Persistencia de Datos por Script (`ScriptDatabase`)

Cada script puede crear o abrir su propio archivo YAML persistente en plugins/DynamicClaims/scripts/data/<dbName>.yml mediante DynamicClaimsAPI.getScriptDatabase(dbName). La escritura a disco utiliza CoalescedAsyncFileWriter y DeferredSave para no bloquear el hilo principal:

Método de `ScriptDatabase` Descripción
db.set(String key, Object value) Asigna un valor a la clave YAML y programa un guardado diferido automático en segundo plano.
db.get(String key, Object def) Obtiene un objeto genérico o devuelve def si no existe.
db.getInt(String key, int def) Obtiene un entero (int) o devuelve el valor por defecto def.
db.getDouble(String key, double def) Obtiene un número decimal (double) o devuelve def.
db.getString(String key, String def) Obtiene una cadena de texto (String) o devuelve def.
db.getBoolean(String key, boolean def) Obtiene un booleano (true/false) o devuelve def.
db.save() / db.saveIfDirty() Fuerza la serialización y escritura asíncrona inmediata si hubo cambios.

4. Ejemplos Reales Funcionando

Ejemplo 1: Sistema de Prestigio Nacional por Construcción (`prestige_system.js`)

Este script incluido en el repositorio otorga puntos de prestigio a una nación cuando sus ciudadanos construyen dentro de su territorio y deposita oro de recompensa en su reserva nacional:

// ==========================================
// SCRIPT: Sistema de Prestigio por Construcción
// Archivo: plugins/DynamicClaims/scripts/prestige_system.js
// ==========================================

Script.setName("Nation Prestige System");
Script.setVersion("1.0");
Script.setDescription("Otorga +1 de Prestigio a una nación por cada bloque colocado.");

var prestigeData = DynamicClaimsAPI.getScriptDatabase("prestige_data");

DynamicClaimsAPI.onEvent("org.bukkit.event.block.BlockPlaceEvent", function(event) {
    var player = event.getPlayer();
    var blockLocation = event.getBlock().getLocation();

    var regionName = DynamicClaimsAPI.getRegionAt(blockLocation);
    if (regionName == null) {
        return;
    }

    var nationName = DynamicClaimsAPI.getNationOfRegion(regionName);
    if (nationName != null) {
        var currentPrestige = prestigeData.getInt(nationName + "_prestige", 0);
        var newPrestige = currentPrestige + 1;
        prestigeData.set(nationName + "_prestige", newPrestige);

        if (newPrestige % 100 === 0) {
            DynamicClaimsAPI.broadcastMessage("§e¡La nación §6" + nationName + " §eha alcanzado §b" + newPrestige + " §epuntos de Prestigio!");
            DynamicClaimsAPI.addNationBalance(nationName, 50.0);
        }
    }
});

// Ejecutable por cualquier jugador con: /dc scripts ejecutar prestigio
DynamicClaimsAPI.registerCommand("prestigio", function(sender, args) {
    if (sender instanceof org.bukkit.entity.Player) {
        var playerNation = DynamicClaimsAPI.getNationOfPlayer(sender.getUniqueId());
        if (playerNation == null) {
            sender.sendMessage("§cNo perteneces a ninguna nación para consultar tu prestigio.");
            return true;
        }

        var currentPrestige = prestigeData.getInt(playerNation + "_prestige", 0);
        sender.sendMessage("§aEl prestigio estructural de tu nación (§e" + playerNation + "§a) es: §b" + currentPrestige + " puntos.");
    } else {
        sender.sendMessage("Este comando es solo para jugadores.");
    }
    return true;
});

Ejemplo 2: Escuchar Eventos Geopolíticos de DynamicClaims

Puedes pasar el nombre completo de cualquier clase de com.wwcstudios.events.* a api.onEvent(...):

Script.setName("Crónicas de Guerra");
Script.setVersion("1.2");
Script.setDescription("Registra estadísticas históricas de guerras y tecnologías.");

var warDb = api.getScriptDatabase("cronicas_guerra");

api.onEvent("com.wwcstudios.events.WarStartEvent", function(event) {
    var atacante = event.getInvadingNation();
    var defensor = event.getDefendingNation();
    var objetivo = event.getGoal().getDisplayName();

    var total = warDb.getInt("guerras_iniciadas", 0) + 1;
    warDb.set("guerras_iniciadas", total);

    api.broadcastMessage("§4⚔ [Crónicas #" + total + "] §c" + atacante + " §7ha iniciado una guerra de §e" + objetivo + " §7contra §9" + defensor + "§7.");
});

api.onEvent("com.wwcstudios.events.TechnologyResearchedEvent", function(event) {
    var nacion = event.getNationName();
    var techId = event.getTechnologyId();
    var techNombre = api.getTechName(techId);
    logger.info("[Ciencia] La nación " + nacion + " completó la tecnología: " + techNombre);
});
